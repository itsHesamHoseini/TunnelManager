# Primary references
[Docker Compose and explicit project names](https://docs.docker.com/compose/compose-file/), [secrets](https://docs.docker.com/reference/compose-file/secrets/).
[Official Docker signed apt installation](https://docs.docker.com/engine/install/ubuntu/), [Debian](https://docs.docker.com/engine/install/debian/). The installer requests explicit opt-in and verifies the signing-key fingerprint; no convenience shell script is downloaded/executed.
[WebSocket library v1.8.15](https://pkg.go.dev/github.com/coder/websocket@v1.8.15), [ACME client](https://pkg.go.dev/golang.org/x/crypto/acme), [QR encoding](https://pkg.go.dev/github.com/skip2/go-qrcode).
[Telegram Bot API](https://core.telegram.org/bots/api): fixed HTTPS bot methods, per-chat approval, two-minute expiry, no arbitrary Telegram commands in M1–M3.
