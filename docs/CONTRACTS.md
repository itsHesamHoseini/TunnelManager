# Contracts
C1 HTTP: JSON errors include stable code, English/Persian message, request ID. Bodies <=64 KiB. Origin checking on writes, Secure HttpOnly SameSite=Strict cookies, hashed session tokens, 12-hour session expiry.
C2 Authentication: Argon2id hashes, bounded expensive-password work; equal unknown-user hashing. Password creates a 2-minute single-use challenge. MFA success rotates to an authenticated session; pending TOTP sessions may only enroll. TOTP replay prevented with monotonic step. Recovery codes stored as hashes, consumed atomically.
C3 Agent identity: enrollment token hashed, expires in 10 minutes, consumed exactly once. Node generates Ed25519 key locally; controller stores public key. Approval required before telemetry/actions. Signed nonce binds node ID, expiry and a fresh challenge. TLS verification cannot be disabled. Frames <=256 KiB, one connection per identity, heartbeat <=30 seconds.
C4 Telemetry: server ID, sample time, scope, CPU deltas, RAM, disk, interfaces, processes, listeners and service metadata. No config contents, environment or process argv. Freshness <=90 seconds. Host network counters are never labelled per-tunnel usage.
C5 Actions: typed IDs and bounded values only. M3 supports read-only collection; command execution reserved for approved future adapters. Unknown actions rejected.
C6 Installer: preview before mutation, atomic state marker, restricted runtime directory, secrets separate from DB, explicit Compose names. Only edge port published; no Docker socket in controller. Rerun keeps secrets/data. Update stages verified binary/UI, snapshots before cutover and restores on failed health.
C7 Maintenance: backup encrypted with independent passphrase, includes DB plus runtime key/config; never prints private material. Restore authenticates before changing anything and requires empty destination or explicit replacement confirmation.
