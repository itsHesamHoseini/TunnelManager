# Contracts
C1 HTTP: JSON errors include stable code, English/Persian message, request ID. Bodies <=64 KiB. Origin checking on writes, Secure HttpOnly SameSite=Strict cookies, hashed session tokens, 12-hour session expiry.
C2 Authentication: Argon2id hashes, bounded expensive-password work; equal unknown-user hashing. Password creates a 2-minute single-use challenge. MFA success rotates to an authenticated session; pending TOTP sessions may only enroll. TOTP replay prevented with monotonic step. Recovery codes stored as hashes, consumed atomically.
C3 Agent identity: enrollment token hashed, expires in 10 minutes, consumed exactly once. Node generates Ed25519 key locally; controller stores public key. Approval required before telemetry/actions. Signed nonce binds node ID, expiry and a fresh challenge. TLS verification cannot be disabled. Frames <=256 KiB, one connection per identity, heartbeat <=30 seconds.
C4 Telemetry: server ID, sample time, scope, CPU deltas, RAM, disk, interfaces, processes, listeners and service metadata. No config contents, environment or process argv. Freshness <=90 seconds. Host network counters are never labelled per-tunnel usage.
C5 Actions: typed IDs and bounded values only. M3 supports read-only collection; command execution reserved for approved future adapters. Unknown actions rejected.
C6 Installer: preview before mutation, atomic state marker, restricted runtime directory, secrets separate from DB, explicit Compose names. Only edge port published; no Docker socket in controller. Rerun keeps secrets/data. Update stages verified binary/UI, snapshots before cutover and restores on failed health.
C7 Maintenance: backup encrypted with independent passphrase, includes DB plus runtime key/config; never prints private material. Restore authenticates before changing anything and requires empty destination or explicit replacement confirmation.
C8 Data removal: explicit keep-data=false removes only the installer-owned postgres subtree. Ownership must match the installation/config directories and every existing parent must resolve without symlinks. Exported backups and unrelated files remain preserved. A populated unowned data directory is never silently adopted.
C9 Native node repair: snapshot executable/config/owned unit before replacing them; failed repair restores the previous unit and its active/enabled state. A failed fresh installation removes only its newly created unit and leaves identity material for explicit repair; pending controller records remain visible.
C10 Reinstall: keeping data retains its marker and setup starts only the owned database before snapshotting it; explicit purge clears its installation marker and obsolete credentials. Moving config/data directories requires authenticated backup and restore into a fresh installation, never an implicit mount change.

C11 Operations v2: approved signed TLS channel supports telemetry plus bounded command polling. Each typed command has a durable UUID, immutable payload digest, expiry and node target; receipts on the node make retries idempotent. No arbitrary programs/shell/paths. One in-flight action per node, two global workers; command payloads with secrets are encrypted in PostgreSQL and never returned as operation logs. Version-1 telemetry remains compatible and cannot execute commands.
C12 Tunnel model: independent ingress bind, engine transport listener/dialer and backend endpoint; a listener node and dialer node determine reverse connection direction independently from traffic direction. One instance may contain many routes. Form settings and validated TOML refer to the same revision. Raw previews/diffs redact tokens and private keys, preserving unchanged secret values.
C13 Ownership/discovery: discovery reads actual systemd/PID/config evidence only; no installation/adoption/rewrite. Route pairing records its evidence and ambiguity; manual import selects both instances/routes and is read-only. Adoption explicitly registers the selected unit/config/binary and expected hashes. Every later mutation checks that evidence and shows all affected routes.
C14 Change protocol: preview validates both nodes, engine version, config, certs, destination and port conflicts; reserved node/port/protocol/bind ranges serialize pending plans. Apply snapshots and prepares both sides before activation. Each node arms a persistent local rollback timer before touching its unit/config. Failed/disconnected/unconfirmed changes revert locally; controller records partial/recovery outcomes. Explicit confirm within 90 seconds commits only after both sides pass checks. Manual file drift or stale revisions block overwrite. Intentional stop/disable is durable.
C15 Diagnostics/logs: typed finite TCP/TLS/HTTP/echo/ping/speed requests have bounded time/bytes and recorded source/target/time. Service active, control TCP/TLS and application reachability are independent observations. Unconfigured application checks remain unknown. Logs are bounded, redacted and searchable; causes are labelled probable. No environment, arbitrary file reads or shell text.
C16 Certificates/recovery: private material encrypted outside node-local root-only files; deploy only to explicitly linked managed instances, with backups/drift checks and reload impact. ACME prerequisites and provider failures are explicit. Recovery targets an adopted/managed unit only, requires sustained thresholds, cooldown, daily limits and persists intentional stops/restart reasons. Panel outage does not stop engines or cancel local rollback.
