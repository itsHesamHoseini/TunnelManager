# TunnelManager contributor instructions
Read README.md, docs/PROGRESS.md, docs/PRODUCT.md and docs/DECISIONS.md first.
Keep product contracts and acceptance evidence current before implementation.
Preserve the calm teal design, Persian RTL and English language support.
Never import environment-specific data or old Git history.
Run scripts/neutrality.mjs and scripts/secrets.mjs before every commit and push.
Production changes are limited to installing this controller and its agent.
Never alter SSH, unrelated services or existing tunnels without explicit adoption.
Do not count simulated data, successful builds or buttons as native integration evidence.
